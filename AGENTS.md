# AGENTS

Záväzné správanie agentov: prečítaj a dodrž **`docs/ai/AGENTS.md`**.

- Najprv plán (`/zenith-plan`), potom kód (`/zenith-implement`).
- Docs k dnešku: `/zenith-rebuild` (nemeniť aplikáciu).
- Triage Gate pred detailným plánom. Bez „pre koho“, „aký problém“ a mantinelov — zastav sa, neplánuj.
- Zadanie bez spustiteľného testu je neplatné.
- Po implementácii spusti test; samo-oprava max 3×, potom človek.
- Log: `.cursor/logs/activity.log`. Harness: `docs/ai/harness.md`.
- Git: https://github.com/matus-babiak/zenith.git
- Základ apky: koreň (`index.html`). UI pravidlá: `CLAUDE.md`.

Ak `docs/ai/product.md` alebo kód hovoria „neznáme“ / súbor neexistuje, nevymýšľaj to.
