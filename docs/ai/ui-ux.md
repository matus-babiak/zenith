# UI / UX — Zenith

**Stav:** Žiadne používateľské rozhranie.  
**Posledné overenie:** 27. 8. 2026.

## Obrazovky

Žiadne. V projekte nie sú komponenty, routy, layouty ani dizajn systém.

## Hlavné toky

Žiadne.

## UX rozhodnutia

Žiadne overené rozhodnutia. Neznáme je napríklad:

- jazyk rozhrania pre koncového používateľa
- svetlá / tmavá téma
- navigácia
- prázdne stavy, chyby, načítanie
- prístupnosť

## Pravidlo pre agentov

Nevymýšľať obrazovky „ako v typickej apke“. Obrazovka vzniká z konkrétnej schválenej potreby. Až bude UI, tento dokument má držať:

- zoznam obrazoviek a ich účel
- tok, ktorý má používateľ zvládnuť
- záväzné UX pravidlá (čo sa nesmie rozbiť)
- mapu: obrazovka → hlavné časti rozhrania → odkiaľ berú údaje
